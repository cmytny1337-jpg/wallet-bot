# Telegram-кошелёк — пошаговый тутор с нуля

Бот, в котором пользователи могут переводить друг другу "деньги"
(на самом деле — просто число в вашей базе данных). Никакой крипты
и блокчейна тут нет — это внутренняя бухгалтерия.

---

## Шаг 1. Создайте бота в Telegram

1. Откройте в Telegram чат **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя (любое) и username (должен заканчиваться на `bot`, например `my_wallet_test_bot`)
4. BotFather пришлёт вам **токен** — длинную строку вида `7123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx`
5. Сохраните этот токен — он понадобится дальше. **Никому его не показывайте.**

## Шаг 2. Установите Node.js

Скачайте и установите с официального сайта: https://nodejs.org (версия LTS)

Проверьте установку в терминале:
```
node -v
npm -v
```
Обе команды должны показать номер версии.

## Шаг 3. Скачайте файлы проекта

Распакуйте архив с этим проектом в любую папку, например `wallet-bot`.
Внутри должны быть файлы: `package.json`, `bot.js`, `database.js`, `README.md`.

## Шаг 4. Установите зависимости

Откройте терминал внутри папки проекта и выполните:
```
npm install
```
Это скачает нужные библиотеки (telegraf для работы с Telegram API,
better-sqlite3 для базы данных).

## Шаг 5. Создайте файл .env

В той же папке создайте файл с именем `.env` (без расширения) и впишите туда:
```
BOT_TOKEN=вставьте_сюда_токен_из_шага_1
ADMIN_IDS=ваш_telegram_id
```

Чтобы узнать свой telegram_id — напишите в Telegram боту **@userinfobot**,
он пришлёт вам ваш числовой ID.

## Шаг 6. Запустите бота

```
npm start
```

Если всё сделано верно, в терминале появится: `Бот запущен ✅`

Не закрывайте терминал — пока он открыт, бот работает.
Если закроете — бот перестанет отвечать (позже поговорим о том,
как оставить бота работать постоянно на сервере).

## Шаг 7. Протестируйте

1. Найдите вашего бота в Telegram по username и нажмите **Start**
2. Отправьте `/balance` — должно показать `0.00`
3. Пополните тестовый баланс командой `/addbalance 100` (сработает,
   только если ваш ID указан в ADMIN_IDS)
4. Попросите друга тоже запустить бота (`/start`), чтобы он появился в базе
5. Отправьте ему деньги: `/send @его_username 10`
6. Проверьте `/history` — увидите операцию

## Как это устроено внутри (простыми словами)

- **database.js** — вся работа с базой данных SQLite. База — это просто
  файл `wallet.db`, который появится в папке проекта после первого запуска.
  Там две таблицы: `users` (кто сколько имеет) и `transactions` (журнал
  операций).

- **Перевод денег** — это не "перемещение" чего-либо, а просто:
  ```
  У отправителя: баланс = баланс - сумма
  У получателя:  баланс = баланс + сумма
  ```
  Обе операции выполняются как единое целое (транзакция БД) — если
  что-то пойдёт не так посередине, обе отменяются, и баланс не портится.

- **bot.js** — обрабатывает команды, которые пишет пользователь,
  и вызывает нужные функции из database.js.

## Что дальше, если захотите развивать проект

- **Красивый интерфейс с кнопками** вместо текстовых команд — можно
  сделать Telegram Mini App (веб-страница, которая открывается прямо
  внутри Telegram) на HTML/React вместо обычных команд бота
- **Постоянная работа 24/7** — разместить бота на сервере (VPS) или
  бесплатной платформе типа Railway / Render, чтобы не держать свой
  компьютер включённым
- **Реальные деньги** — если захотите, чтобы люди закидывали и выводили
  настоящие USDT или рубли, потребуется отдельная интеграция с
  платёжным шлюзом или блокчейном, плюс — почти наверняка — юридическая
  регистрация (лицензия), так как это уже финансовые услуги
- **Защита от ошибок** — например, лимиты на сумму перевода, подтверждение
  перед отправкой ("Вы уверены?"), логирование подозрительной активности

## Частые ошибки

- **"Cannot find module 'telegraf'"** → не выполнили `npm install`
- **Бот не отвечает** → проверьте, что терминал с `npm start` открыт
  и не выдал ошибку; проверьте правильность токена в `.env`
- **"Получатель не найден"** → получатель ещё ни разу не писал боту
  `/start` — без этого бот не знает о его существовании
